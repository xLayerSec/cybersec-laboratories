# Cybersec Laboratories

Repositorio centralizado para la documentación y analisis de laboratorios de seguridad y entornos de prueba.

## Estructura

* **`metasploitable2/`** - Laboratorio para pruebas de penetración y explotación de servicios.
* **`crapi/`** - Entorno de práctica para análisis de seguridad y vulnerabilidades en APIs.
